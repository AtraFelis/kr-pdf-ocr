# DPI·검출 표시·임의 영역 재인식

## OCR 해상도

왼쪽 **OCR 해상도(DPI)**에서 200/300/400/600을 선택한다. 기본 300이며 다음 OCR 작업에서 실제 CLI `--dpi`로 전달하고 `summary.json.dpi`에 저장한다. 미리보기는 96 DPI를 유지하며 추출 범위는 상대 좌표여서 확대·해상도 변경에도 같은 비율을 적용한다. **OCR 설정 기본값 복원**은 DPI 300·검출 기준 0.50만 되돌린다. 결과·편집본·모델·장치는 변경하지 않는다.

고해상도는 작은 문자에 유리할 수 있지만 시간·메모리가 늘고 낮은 해상도 스캔의 사라진 세부 정보를 복구하지 않는다. 설정의 세부 의미는 [OCR 설정](OCR_SETTINGS.md)을 따른다.

## 실제 검출 영역 표시

OCR 후 미리보기 위의 **검출 영역 표시**를 켜면 현재 페이지의 원시 줄 다각형을 녹색으로 표시한다. 전체 페이지 좌표를 상대 좌표로 환산해 현재 미리보기 크기·확대율에 적용한다. 영역을 자른 OCR도 전체 페이지로 변환된 좌표를 사용한다. 빈 페이지·다른 페이지로 전환하거나 새 OCR을 시작하면 이전 다각형은 지운다.

저장된 현재 결과의 좌표만 사용하며 없는 좌표를 생성하지 않는다. VLM의 전체 페이지 TXT처럼 좌표가 없으면 표시하지 않는다. Markdown의 구조 블록 표시·신뢰도 색상·제외 이유별 표시는 이번 기능이 아니다. 사각형이 없는 부분은 누락일 수도 있고 이미지나 빈 공간일 수도 있으므로 원본과 대조한다.

## 완전히 누락된 영역 다시 읽기

1. TXT 출력 모드에서 원하는 PDF 페이지를 연다.
2. **재인식 영역 선택**을 체크하고 다시 읽을 부분을 드래그한다. 기존 페이지·추출 영역은 유지한다.
3. **선택 영역 재인식**을 누른다. 기존 OCR 줄 목록에 없어도 실행할 수 있다.
4. 비교 창에서 PP-OCRv5·VL 1.6·Qwen 중 모델과 DPI·장치를 고르고 **선택 영역 다시 읽기**를 누른다. PP 검출 기준은 창을 열 때의 화면 값을 고정한다.
5. 같은 영역으로 여러 번 실행해 후보를 쌓고 입력 이미지와 원시 문자를 비교한다. 원하는 후보를 **복사**하거나 **편집기 커서 위치에 삽입**한다. 삽입 위치는 자동 추정하지 않으며, 선택된 기존 텍스트를 덮어쓰지 않는다. 삽입은 실행 취소할 수 있다. 파일 저장은 별도로 한다.

재인식은 현재 PDF를 지정 DPI로 다시 렌더링해 명시적으로 선택한 상대 영역만 OCR한다. 주 작업의 추출 영역과 독립적인 사용자 요청이며 기존 원시 줄·사전·문단 결과를 바꾸지 않는다. 후보는 Kiwi·사전 보정 없이 원시 글자를 보여준다. 한자·공백·문장부호를 원본과 비교한다. VLM이 토큰 상한에 도달한 결과나 빈 결과는 채택 가능한 후보로 표시하지 않는다.

작업은 별도 프로세스에서 로컬로 진행한다. 매 실행은 `output/region-retry-작업ID/result/`의 새 경로에 원시 JSON·TXT·입력 이미지·실행 설정을 저장하고 이전 파일을 덮어쓰지 않는다. 완료 후보는 비교 창 안에서 유지하며 창을 닫은 뒤에도 실행 파일은 보존한다. 후보 목록을 저장 결과에서 다시 불러오는 전용 UI는 아직 없다. 창의 **재인식 취소**, Escape·닫기는 소유한 프로세스만 중단한다. 완료된 이전 후보와 다른 작업·편집 내용은 유지한다.

Markdown 편집기에 임의 TXT 후보를 삽입하지 않도록 새 영역 선택은 TXT에서만 활성화한다. 이 기능은 위치를 읽는 OCR이며 별도 언어 모델의 문장 교정·학습을 도입하지 않는다. 특정 모델이 항상 정답을 내거나 DPI가 높을수록 항상 개선된다고 보장하지 않는다.
