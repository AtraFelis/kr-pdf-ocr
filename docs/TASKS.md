## 다음 개발 우선순위

17페이지 전체 영역의 대사 누락은 검출 영역 점수 기준을 명시적으로 0.6에서 0.5로 낮춰 수정했다. 저장된 전체 페이지 이미지의 CPU·GPU 재실행에서 원시 결과·Kiwi 후 TXT 모두 대사를 포함하고, 다른 샘플 4페이지의 전후 결과는 동일했다. 이는 모든 문서의 누락 해결을 보장하지 않는다. [검출 누락 수정 기록](history/OCR_DETECTION_OMISSION.md)을 따른다. 저장 JSON 재보정만으로 없는 글자를 복원하지 않는다.

기준일: 2026-10-13. [PR #8](https://github.com/AtraFelis/kr-pdf-ocr/pull/8)은 병합됐으며 `main`에 아래 구현이 포함된다.

- 고유명사 사용자 사전·모델 정보·VL 1.6 구조화 Markdown과 이미지 저장.
- `sample_ocr_err.pdf` 2페이지에서 작은 닫는 따옴표 때문에 문단 복원·Kiwi가 중단되던 문제 수정. 샘플 1~2페이지의 적용과 원시 결과 보존 확인.
- 한글 인용문의 여는 따옴표 앞 공백 보완.
- PP-OCRv5 재인식 후보 비교, 선택 줄의 VL 1.6·Qwen 재인식, 후보의 편집기 반영·실행 취소.

페이지 사이 문단 연결을 PP-OCRv5 TXT의 선택 옵션으로 구현했다. [사용법](PAGE_CONNECTION.md)과 [실행 범위](history/PAGE_CONNECTION.md)를 따른다. 모델 학습·언어 모델 문장 교정은 사용자 결정으로 제외하고 미병합 평가 PR #10을 닫았다. 과거 검사 수치를 이번 변경의 결과로 사용하지 않는다.

PR #12의 내부 빈 줄 리뷰와 17페이지 드문 겹침 재발을 수정하고 회귀 검사를 확인했다. [확인 범위](history/PR12_REVIEW_AND_PAGE17.md)를 따른다. 다음 우선순위는 상세 보정 제외 확인 화면·부분 복원 품질 확대 → 제목·목록·각주·단어 경계 품질과 Markdown 구조 품질 확대 → CPU/GPU 자원·오프라인·Windows 배포 검증이다. 짧은 대사 재인식의 다양한 문서 품질 확대도 계속한다.

사용자 사전은 합성 사례의 품질·입력·저장·화면 흐름을 확인했다. 실제 문서별 품질 확대와 VLM 사전 활용은 추가 평가한다.

텍스트 중심 문서는 PP-OCRv5 + TXT, 복잡한 문서는 VL 1.6 + Markdown을 추천하는 별도 흐름으로 진행한다. Markdown은 샘플 실행·저장·취소를 확인했으며 [설계 문서](MODEL_AND_EXPORT.md)를 따른다.
