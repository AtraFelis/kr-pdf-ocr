# 개발 목록

상세 요구사항은 PLAN.md를 기준으로 합니다.

## 다음 개발 우선순위

[고유명사 사용자 사전](USER_DICTIONARY.md)·모델 정보·구조화 Markdown의 첫 연결을 제공한다. 샘플의 GPU 2페이지·저장·취소와 CPU 부분 영역을 검증했다. PR #8 리뷰 수정은 회귀 검사와 기존 샘플 결과의 편집·미리보기·저장을 확인했다. 아래 항목은 예정 순서이며 새 모델을 확정하거나 설치한 상태가 아니다.

1. 특정 페이지의 문단·띄어쓰기 보정 결과와 설정 대조, 제외 이유 표시와 정상 영역의 부분 복원.
2. 짧은 대사·문장부호 오류 영역의 여백·해상도·재인식 비교와 원본 확인 화면.
3. 한국어 문자 교정 모델 비교: `Soyoung97/gec_kr` 우선, KoGEC는 배포·사용 조건 확인 후 후보 결정. 정상 문장·고유명사 보존을 함께 평가.
4. 제목·목록·각주·단어 연결·페이지 간 문단 연결과 대표 Markdown 문서의 표·수식·읽기 순서 품질 확대.
5. CPU/GPU 성능·메모리·오프라인 처리·Windows 배포 검증.

사용자 사전은 합성 사례의 품질·입력·저장·화면 흐름을 확인했다. 실제 문서별 품질 확대와 VLM 사전 활용은 추가 평가한다.

텍스트 중심 문서는 PP-OCRv5 + TXT, 복잡한 문서는 VL 1.6 + Markdown을 추천하는 별도 흐름으로 진행한다. Markdown은 샘플 실행·저장·취소를 확인했으며 [설계 문서](MODEL_AND_EXPORT.md)를 따른다.
