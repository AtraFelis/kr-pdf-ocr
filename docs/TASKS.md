# 개발 목록

상세 요구사항은 PLAN.md를 기준으로 합니다.

## 1. OCR 가능성 확인

- [x] 프로젝트 전용 Python 환경과 PaddleOCR CPU 엔진 설치
- [x] 공식 문자 검출·한국어 인식 모델을 로컬에 다운로드
- [x] 샘플 1~2페이지 OCR 및 원시 TXT·위치·신뢰도 저장
- [x] 첫 페이지 원문과 결과 비교: 작은 한자 누락·공백 오류 확인
- [x] 첫 페이지 정답 TXT 초안 작성 및 문자·공백 오류 비교 도구 추가
- [x] 명확한 병기 한자 제외 및 원시 OCR 결과 보존
- [x] PaddleOCR-VL·Qwen 후보 추가 및 샘플 한국어 품질 비교
- [x] RTX 5070 CUDA 실행 확인
- [x] PP-OCRv5의 CPU·GPU 선택 및 GPU 실행 환경 확인
- [ ] 실제 사용할 대표 PDF와 원하는 TXT 준비
- [ ] 한국어·영어 혼합 및 한자 병기 제외 검증 샘플 확보
- [ ] 로컬 모델 후보의 문자 인식 및 위치 정보 비교
- [ ] CPU 실행, 처리 속도, 메모리 및 배포 조건 확인
- [ ] OCR 모델과 개발 도구 결정
