# 개발 목록

상세 요구사항은 PLAN.md를 기준으로 합니다.

## 다음 개발 우선순위

[고유명사 사용자 사전](USER_DICTIONARY.md)의 첫 구현을 완료했다. 모델 정보 아이콘도 구현했으며 구조화 Markdown도 첫 연결을 구현했으며 샘플의 GPU 2페이지·저장·취소와 CPU 부분 영역을 검증했다. 다음 작업은 대표 문서 품질 확대 평가다.

1. 추가 대표 문서와 정답 구조 확보·글자/공백·표/수식·읽기 순서 품질 평가.
2. 제목·목록 보존, 페이지 간 문단 연결과 검토 화면 개선.

사용자 사전은 합성 사례의 품질·입력·저장·화면 흐름을 확인했다. 실제 문서별 품질 확대와 VLM 사전 활용은 추가 평가한다.

텍스트 중심 문서는 PP-OCRv5 + TXT, 복잡한 문서는 VL 1.6 + Markdown을 추천하는 별도 흐름으로 진행한다. Markdown은 샘플 실행·저장·취소를 확인했으며 [설계 문서](MODEL_AND_EXPORT.md)를 따른다.
