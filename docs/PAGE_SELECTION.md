# 페이지·영역 선택

명령행과 JSON 설정뿐 아니라 데스크톱 화면에서도 지정할 수 있다. 페이지 체크·마우스 선택·좌표 입력은 [데스크톱 사용법](DESKTOP_APP.md)을 참조한다. 아래는 명령행 설정이다.

## 페이지 선택

- `--pages all`: 전체 페이지. 생략해도 전체 페이지다.
- `--pages 1,3,5-7`: 지정한 페이지와 범위. 중복을 제거하고 PDF 순서로 처리한다.
- `--exclude-pages 2,6-7`: 선택한 페이지 중 제외한다.
- 번호는 PDF의 첫 페이지부터 1로 센다. 잘못된 범위나 전체 제외는 OCR 전에 오류로 안내한다.

## 영역 지정

회전을 반영한 페이지 미리보기의 왼쪽 위를 기준으로 다음 옵션 중 하나를 사용한다.

- `--region 0,0.2,1,0.8`: 왼쪽·위쪽·오른쪽·아래쪽 상대 좌표(0~1).
- `--y-range 200,800 --reference-height 1000`: 높이 1,000px의 기준 이미지에서 위 200~800px. 가로는 전체이며 기준 높이를 생략하면 1,000이다.
- `--region-px 100,200,900,800 --reference-size 1000,1000`: 기준 이미지의 너비·높이와 사각형 픽셀 좌표. 실제 OCR 해상도의 픽셀과 구분한다.

상대 좌표를 저장하고 각 페이지의 렌더링 크기에 맞춰 환산한다. DPI가 바뀌어도 같은 비율을 사용한다. 여백이 서로 다른 페이지에는 페이지별 설정을 사용한다.

## 페이지별 설정

`--regions-file 경로`에 다음 JSON을 지정한다. 키는 PDF 페이지 번호이고 값은 상대 좌표 4개다.

```json
{
  "1": [0, 0.2, 1, 0.8],
  "3": [0.1, 0.15, 0.9, 0.85]
}
```

페이지별 설정은 공통 영역보다 우선한다. 미지정 페이지는 공통 영역을, 공통 영역도 없으면 전체 페이지를 사용한다. 제외된 페이지는 처리하지 않는다. 범위를 벗어난 페이지나 잘못된 좌표는 오류다. 실제 문서용 설정은 `output/` 등 추적 제외 폴더에 저장한다.

## 실행과 결과

```powershell
.\.venv\Scripts\python.exe -m pdf_ocr.cli samples/input/sample.pdf --pages 1-3 --exclude-pages 2,3 --region 0,0.2,1,0.9 --repair-spacing --output "output/selection-$(Get-Date -Format yyyyMMdd-HHmmss)"
```

OCR 전에 잘라내므로 영역 밖의 글자는 인식하지 않는다. 경계에 걸친 문자는 잘릴 수 있어 미리보기를 확인해야 한다. 영역을 자동 확장하거나 잘린 문장을 추측하지 않는다.

- `page-001.png`: 전체 이미지.
- `page-001-selection.png`: 선택 영역의 빨간 테두리 미리보기.
- `page-001-input.png`: OCR에 넣은 잘린 이미지.
- `page-001-raw.txt` 및 `page-001.txt`: 원시 결과 및 병기 제외·복원 결과.
- `combined.txt`: 완료된 선택 페이지를 순서대로 합친 TXT. 페이지 사이에 빈 줄을 두고 문단 연결은 하지 않는다.
- `page-001.json`: 전체 크기, 상대 영역, 픽셀 범위와 인식 결과. `polygon_in_input`은 잘린 이미지 좌표, `polygon`은 전체 페이지 좌표, `relative_polygon`은 전체 페이지 비율이다. 좌표 없는 VLM 결과는 null을 유지한다.

## 검증

합성 PDF로 범위·제외·빈 선택, 200~800px 환산, 해상도 변경, 90도 회전, 페이지별 우선 적용, 원본 좌표 보존과 통합 TXT를 확인했다. 실제 샘플은 1~3페이지 중 2~3을 제외하고 1페이지의 세로 20~90%만 처리했다. 제목과 하단 쪽수가 제외되고 본문 5개 문단이 저장됨을 확인했다. 결과는 `output/region-run-01`이다.
