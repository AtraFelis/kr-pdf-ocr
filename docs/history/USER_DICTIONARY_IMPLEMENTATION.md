# 고유명사 사용자 사전 구현·검증 기록

날짜: 2026-10-12. 요구사항은 [사용자 사전](../USER_DICTIONARY.md), 다음 작업은 [개발 목록](../TASKS.md)을 참조한다.

## 변경

- 불변 버전 1 사전, JSON 읽기·저장, BOM 허용 TXT 가져오기/내보내기, 중복 정리·충돌/잘못된 입력 거부를 추가했다.
- Kiwi에 NNP·score=0.0으로 사용자 단어를 등록하고 기본 Kiwi를 분리해 동일 입력의 사전 미적용 결과도 기록한다. 공백 외 글자 보존 검사는 양쪽에 적용한다.
- 이름·버전·단어 수·SHA-256 식별값과 당시 사전 파일을 기록한다. GUI는 별도 작업 스냅샷으로 사전을 고정한다.
- GUI의 사전 선택·관리와 저장 원시 OCR 재보정·별도 비교·TXT 내보내기를 연결했다. 현재 편집본은 재보정 입력이나 출력으로 사용하지 않는다.
- 저장 OCR의 단일 JSON과 결과 폴더를 지원한다. 페이지 번호 중복을 거부하며 새 출력 폴더에만 기록한다. 완료 결과는 취소·뒤 페이지 실패 후에도 보존한다.
- `user_data/`는 Git에서 제외한다. 실행 중 다운로드나 외부 문서 전송 기능은 추가하지 않았다.

## 검사 조건과 결과

Python 3.12, Kiwi·모델 0.24.0, PySide6 offscreen에서 확인했다. PP-OCRv5는 기존 `.venv-paddle` PaddlePaddle-GPU 3.2.2 / CUDA 12.9 환경을 사용했다. GPU는 NVIDIA RTX 5070이다.

- pytest **87개 통과**. 기존 검사와 사전 입력·저장·품질·화면 검사를 포함한다.
- 실제 로컬 Kiwi로 단일·복합 이름·조사·줄 경계·겹치는 일반 단어와 문단 보존을 확인했다.
- 합성 문장 `푸른별연구소에서 하루카를 만났다.`는 기본 Kiwi에서 이름이 나뉘었고 사전 등록 후 `푸른별 연구소에서 하루카를 만났다.`가 됐다.
- 일반 문장 2개의 사전 적용 결과는 기본 Kiwi와 같았다. 이것을 모든 문서의 개선이나 악화 없음으로 일반화하지 않는다.
- 실제 재보정 QProcess가 사용자 편집 내용과 수정 상태를 유지하고 비교 창을 여는지 확인했다. 취소·부분 실패의 보존, 미저장 사전 닫기 거부, 가져오기 실패와 저장·삭제·내보내기 확인도 검사했다.
- 합성 PDF 한 페이지를 CPU와 GPU에서 실제 OCR → Kiwi 사전 보정 → TXT/JSON으로 처리했다. CPU 페이지 처리 5.69초·RSS 약 1,636MiB, GPU 2.36초·RSS 약 2,554MiB였다. 이는 해당 실행의 OCR·복원·보정 합계이며 일반 성능 비교나 GPU 메모리 측정이 아니다. 모델 초기화와 Kiwi 초기화 시간은 페이지 시간에 포함되지 않는다.
- 해당 OCR의 Python 소켓 연결 차단과 로컬 모델 경로 사용을 확인했다. 저장 OCR의 CLI 재보정도 실행했다.
- 메인 창·사전 관리·비교 창의 합성 자료 화면 이미지를 생성해 배치와 한글 안내를 확인했다. 파일은 Git에서 제외된 `output/dictionary-smoke/`에 보관한다.
- Docstring 누락 검사·Ruff·포맷 검사는 Python 29개 파일에서 통과했다. Markdown 19개 문서의 로컬 링크·앵커 86개와 공백 검사도 통과했다.

처음 pytest 실행에서 샌드박스의 기본 임시 경로에 폴더를 만들지 못해 22개 준비 오류가 발생했다. 프로젝트 내부의 매번 새로운 `output/pytest-작업ID`를 지정해 재실행했고 최종 87개가 통과했다. AGENTS.md의 검사 명령도 새 로컬 임시 경로를 지정하도록 갱신했다. 실제 모델·PDF·출력·사전은 커밋에 포함하지 않는다.

## 남은 제한

실제 사용자 문서 전체의 고유명사와 일반 문장 품질, 큰 사전·장문 문서의 자원 사용, 실제 Windows 화면의 다양한 DPI와 크기는 추가 평가한다. 사전 등록이 항상 해당 표기를 강제하는 것은 아니다. 두 Kiwi 인스턴스를 준비해 비교하므로 사전 미선택보다 메모리·처리 비용이 늘 수 있다.

VL·Qwen 사전 적용과 OCR 글자 오류 치환은 제공하지 않는다. 좌표 없는 결과에 사전을 요청한 재보정은 이유를 알리고 중단한다. 화면의 다른 저장 작업은 단일 페이지 JSON을 열며 여러 저장 페이지의 폴더 재보정은 CLI를 사용한다. 편집본 자동 병합·글자별 강조는 후속 작업이다.
