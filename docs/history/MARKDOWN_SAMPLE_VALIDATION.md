## 발견·수정한 프로그램 오류

앱 미리보기에서 공식 Markdown의 HTML 이미지 컨테이너와 백분율 너비가 Qt 표시 방식과 맞지 않아 이미지가 제목과 겹쳤다. 사용자가 다른 뷰어에서는 정상이라고 확인했으며 내보낸 Markdown 원문의 오류로 처리하지 않았다.

수정은 표시용 문서에만 적용한다. 그림 전용 HTML 컨테이너를 독립 문단으로 표시하고 너비를 미리보기 기준으로 계산한다. 그림은 표시할 때만 축소하고 파일은 바꾸지 않는다. 표시용 문서를 갱신해 같은 경로의 그림 크기·작업 변경에 이전 캐시를 사용하지 않는다. Qt 문서 자원 로더에도 결과 내부 이미지 정책을 적용해 외부 URL·결과 밖 파일을 차단한다.

실제 샘플의 수정 후 화면에서 그림과 제목이 분리되는 것을 확인했다. 창이나 미리보기 폭이 바뀌면 그림 너비를 다시 계산하고 스크롤 위치를 유지한다. 저장 원문과 원본 이미지에는 미리보기 변경을 반영하지 않는다.

실제 Tab·Space·Escape 동작 검사에서 설명 창을 닫은 뒤 초점이 돌아오지 않는 사례도 발견했다. 원래 창을 활성화한 뒤 정보 아이콘에 초점을 돌리도록 수정했다.

## 자동 검사

기존 88개 검사에 합성 자료 기반 Markdown 검사 19개를 추가해 총 **107개 통과**했다. 구조 입력/전체/상대 좌표, 표·수식·원시 결과 보존, 이미지 누락 오류, 한글·공백 저장 경로와 URL 인코딩, 승인 없는 덮어쓰기, 경로 탈출·누락 자원 거부, 실제 Qt 문서의 외부 자원 차단, 그림 크기 변경·작업 변경 캐시, HTML 이미지와 제목 배치, 다음 작업 형식 독립, 취소·뒤 페이지 실패 결과 보존, 미지원 CLI 조합과 실제 키보드·초점 복귀를 포함한다.

Python 파일 34개의 Docstring·Ruff·포맷 검사, 문서 링크·앵커 104개와 공백 검사도 통과했다. 샘플 PDF·이미지·출력·실제 정답을 테스트 소스에 포함하지 않았다.

## 인식 품질과 제한

원본과 결과를 시각적으로 대조해 단 구분·읽기 순서, 표 표현, 일부 수식 표기와 이미지 보존을 확인했다. 그러나 일부 한글 글자 치환·공백 누락이 남아 있다. 모델 인식 오류와 이번 미리보기 오류를 구분하며 문서 전체의 정답 대조·CER을 산출한 것으로 표현하지 않는다. 구조 블록에는 Kiwi를 적용하지 않았다.

복잡한 표·여러 문서의 일반화·수식 전반·CPU 전체 문서의 시간/메모리·다양한 DPI는 추가 평가한다. 이번 문서는 그림을 포함하지만 모든 종류의 수치 차트 이해를 검증한 것이 아니다. 페이지 간 표 병합과 수식 조판은 후속 기능이다. 기존 PR #8에 검사와 수정·기록을 누적하며 사용자가 되돌린 Draft 상태는 유지한다.
