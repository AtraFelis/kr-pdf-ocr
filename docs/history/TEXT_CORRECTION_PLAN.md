# 한국어 문자 교정 도입 계획

날짜: 2026-10-13. 사용자가 OCR의 글자 오류, 특정 페이지의 보정 누락, 짧은 대사와 문장부호 누락을 제기했고 문자 교정 모델 평가를 계획에 추가하도록 요청했다. 현재 단계는 계획이며 모델 설치·추론·교정 정확도 검증을 수행한 기록이 아니다.

## 근거와 후보

현재 Kiwi 경로는 형태소 분석을 이용한 공백 보정이며 공백 외 글자 변경을 거부한다. 이 경로에서 `훌륨한 → 훌륭한`을 교정하지 않는다. 특정 페이지에서는 좌표 누락·겹침 판단으로 문단 복원을 중단하면 Kiwi도 건너뛸 수 있다. 초기에는 사용자 예시의 원인이 미확인이었으나, 이후 제공된 `sample_ocr_err.pdf` 2페이지는 작은 닫는 따옴표가 별도 영역으로 검출돼 전체 복원이 제외된 것을 확인하고 수정했다. [수정·검증 기록](OCR_ERROR_SAMPLE.md)을 참조한다. 다른 좌표 누락·미해결 겹침의 부분 복원은 아직 구현하지 않았다.

- [SKT KoBART](https://github.com/skt-ai/kobart)는 한국어 기반 모델이다. 기본 모델과 교정용으로 추가 학습된 모델을 구분한다.
- [Soyoung97/gec_kr](https://huggingface.co/Soyoung97/gec_kr)는 공개된 한국어 교정 모델이므로 첫 로컬 비교 후보로 삼는다. 특정 글자 치환·소설·고유명사·OCR 오류의 효과는 직접 평가하기 전까지 미확인이다. 배포·제품 사용 전에 라이선스와 파일·실행 조건을 확인한다.
- [KoGEC 연구](https://arxiv.org/abs/2506.11432)는 NLLB를 한국어 오류 교정에 추가 학습한다. 연구의 평가 결과를 우리 PDF 정확도로 간주하지 않으며 배포 가중치·사용 조건부터 확인한다.

짧은 대사와 작은 문장부호는 원본 영역을 재인식하는 방법을 먼저 비교한다. 텍스트 교정으로 원본에 없던 대사·내용을 추측해 넣지 않는다. 모델은 원문·후보·변경 위치를 제공하는 선택 기능으로 평가하고 기존 Kiwi·사전의 문자 보존 정책은 유지한다. 원시 결과·편집본은 덮어쓰지 않는다.

## 예정 순서와 평가

2026-10-13 갱신: PR #8 리뷰 수정, 오류 샘플의 작은 닫는 부호로 인한 보정 중단 수정, 인용문 앞 공백 보완, 짧은 대사의 PP-OCRv5 후보 비교·VL 1.6/Qwen 재인식·편집기 반영이 병합됐다. 다음은 `gec_kr` 로컬 비교 평가 → 유효한 경우 원문·교정 후보 비교와 사용자 채택 → 미해결 좌표 문제의 안내·부분 복원 및 문단/구조 품질 확대 → 성능·배포 검증이다. 문자 교정 모델은 아직 설치하지 않았고 제품 연결 여부는 평가 후 결정한다.

같은 자료에서 글자·공백·문단·문장부호 오류와 정상 문장의 과잉 교정을 나눠 측정한다. 고유명사·숫자·영어·대사 말투를 보존하는지, 실행 시간·메모리·로컬 처리 조건을 확인한다. 교정 전후 비교 없이 모델을 확정하지 않는다. 추가 학습은 공개·합성 자료를 확보하고 기존 후보의 한계를 확인한 뒤 검토한다.

상세 요구사항은 [기획서](../PLAN.md), 예정 작업과 완료 여부는 [개발 목록](../TASKS.md)에서 관리한다.
