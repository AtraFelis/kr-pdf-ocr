# 17페이지 대사 검출 누락 조사·수정

기준일: 2026-10-13. PR #12의 문단 보정 누락과 별개로 사용자 제보의 대사 한 줄이 최신 전체 페이지 원시 OCR에서 빠지는 현상을 조사했다. 실제 문서·원문·사용자 사전·결과는 Git에 포함하지 않는다.

## 문서 최신화 및 원인

수정 전에 PLAN·TASKS·TEXT_RESTORATION에 원시 결과의 문장 누락과 문단/Kiwi 보정 누락을 구분하고 조사 우선순위를 등록했다. 완료 후 실제 확인 범위로 갱신했다. 기존 드문 겹침 수정은 유효하며 이번 문제까지 해결했다는 의미가 아니다.

최신 실행의 저장된 300 DPI 전체 페이지 PNG를 같은 PP-OCRv5 mobile 검출·한국어 인식 모델로 읽었다. 설치된 PaddleX OCR 파이프라인 코드와 반환된 설정에서 검출 영역 점수 기준 `box_thresh=0.6`, 인식 점수 기준 `text_rec_score_thresh=0`을 확인했다.

- 기본 기준 0.6: 검출/인식 영역 22개. 대사 영역 없음.
- 인식 점수 기준 0으로 명시: 여전히 22개. 인식 후 점수 필터 문제가 아님.
- 검출 해상도 제한을 전체 긴 변 2,140px로 명시: 여전히 22개.
- 검출 영역 기준 0.5 및 0.4: 각 23개. 두 경우 모두 누락된 대사 포함.

확인된 원인은 해당 대사 영역이 기본 검출 영역 기준을 통과하지 못한 것이다. 영역의 정확한 검출 점수는 반환되지 않아 생성하지 않았다. 대사의 한국어 인식 점수는 약 0.79이며 검출 영역 점수와 다르다. 문단 복원이나 Kiwi가 이 문장을 삭제한 것이 아니다.

## 변경

- 로컬 Paddle 엔진 초기화 시 `text_det_box_thresh=0.5`를 명시한다. 선택 영역 밖까지 검색하거나 문장을 추측으로 만들지 않는다.
- CPU·GPU 및 같은 엔진의 단일 줄 재인식에 동일하게 적용한다. 선택 줄 VLM 경로가 사용하는 PP 검출기에도 적용되며 그 경로의 추가 품질은 이번에 평가하지 않았다. 공식 VL 1.6 Markdown 파이프라인은 별도 엔진이다.
- 실제 전달 설정을 PP TXT 실행의 `summary.json.ocr_settings`에 저장한다. 값이 제공되지 않는 다른 엔진은 null이다.
- 새로 실행한 모델의 글자·인식 신뢰도·좌표를 그대로 보존한다. 과거 출력·사용자 편집본·모델 파일은 수정하지 않는다.

## 검증

- GPU 비교: `sample.pdf` 1~2페이지 및 `sample_ocr_err.pdf` 1~2페이지 총 4페이지의 기준 0.6/0.5 결과는 텍스트·점수·좌표까지 동일했다.
- 오류 전체 이미지 17페이지: 기존 22개 영역의 좌표를 모두 유지하고 대사 영역 1개를 추가했다. 인식 배치가 달라지면서 기존 일부 글자·점수는 변했으므로 17페이지의 모든 인식 결과가 동일하다고 표현하지 않는다.
- 같은 전체 이미지와 최신 실행에서 저장한 사용자 사전으로 CPU·GPU 모두 새 OCR 및 Kiwi를 실행했다. 원시 결과와 최종 TXT에 대사를 포함하고 정상 문단 복원이 적용됐다. 각 23개의 원시 줄 인덱스가 최종 문단에 한 번씩 보존됐다.
- GPU 두 페이지 CLI 실행·PNG/JSON/원시 TXT/최종 TXT/통합 TXT 저장 및 설정 기록을 확인했다. 문서 처리의 소켓 연결은 차단했다.
- 17페이지 OCR·Kiwi 처리 시간: GPU 약 3.68초, CPU 약 13.13초(초기화 제외). 처리 후 프로세스 RSS 약 2.42/2.59GB. 두 엔진을 같은 검증 프로세스에서 순차 초기화했으므로 독립 CPU 메모리 요구량이나 보장 성능이 아니다.
- 합성 대역으로 CPU/GPU 초기화 설정, 재인식 글자·점수·좌표 보존과 CLI 설정 기록을 검사했다. 관련 24개 및 전체 pytest 163개 통과. Python 41개 Docstring·Ruff·포맷 검사 통과.

## 남은 제한과 사용 방법

프로그램을 재시작하고 같은 PDF·영역을 OCR로 다시 읽는다. 저장 JSON 재보정은 없는 문장을 복원하지 못한다. 기존 줄 선택 재인식도 검출 자체가 없는 줄을 발견하는 기능은 아니다.

대사 첫머리의 반복 글자는 여전히 오인식하며 Kiwi가 그 잘못된 글자 사이에 공백을 넣을 수 있다. 다른 단어·문장부호 오류도 남아 있다. 이번 변경은 문장 누락을 줄이기 위한 검출 수정이며 문자 교정 모델을 도입하지 않았다. 낮은 검출 기준은 다른 문서에서 잡음 영역을 늘릴 수 있어 다양한 자료 품질 비교가 필요하다.

원본 439페이지 PDF는 이번 검증에서 다시 열지 않았고 동일한 저장 입력 이미지를 사용했다. 로컬 samples의 PDF들은 각각 11페이지와 3페이지이므로 17페이지 직접 호출은 범위 오류로 중단했으며 통과로 계산하지 않았다. GUI 실제 조작·VLM·Markdown·다양한 DPI·오프라인 OS 네트워크 차단은 이번에 재검증하지 않았다.
