# OCR 모델 선택 기준

공식 지원 범위 확인일: 2026-10-12. 지원 언어나 버전이 바뀌면 관련 모델 도입과 함께 갱신한다.

- **PaddleOCR**은 전체 OCR 프로젝트·도구 모음이다. **PP-OCR**과 **PaddleOCR-VL**은 그 안의 서로 다른 모델 계열이다.
- **PP-OCRv5 한국어 모델**은 한국어·영어 글자 인식과 줄 영역 좌표·신뢰도를 제공하며 CPU 또는 GPU에서 실행할 수 있다. 초기 CPU 실행은 설치·비교 기준을 만들기 위한 설정이었다. 현재 화면에서는 모델과 처리 장치를 별도로 선택한다. 최종 모델로 확정한 것은 아니다.
- **PP-OCRv6**은 정확도·속도가 개선된 계열이지만, 현재 공개 인식 모델의 지원 목록에는 한국어가 없다. 중국어·영어·일본어·라틴 문자 계열 언어의 성능 수치를 한국어에도 적용하지 않는다. v6 검출기와 v5 한국어 인식기를 조합하는 방법은 미검증 후보다.
- **PaddleOCR-VL 1.6**은 1.5와 호환되는 구조의 개선 모델이다. 한국어 샘플에서 1.5보다 좋은지 같은 입력·해상도·실행 방식으로 확인한다. 기존 1.5 선택은 초기 실행 예제에 따른 시험 선택이며, 최신 버전 비교가 누락된 부분을 보완한다.
- 모델의 문서 파싱 벤치마크와 한국어 글자 정확도는 구분한다. 1.5의 직접 요소 인식 방식에서 발생한 실패를 전체 문서 파이프라인이나 1.6의 성능으로 일반화하지 않는다.

우리 프로젝트는 한국어·영어와 문단 복원을 우선하고 명확한 한자 병기는 제외한다. 모델 선택은 같은 샘플에서 문자 오류·공백 오류·위치 정보·실행 시간과 메모리를 비교해 결정한다.

VL 1.6을 현재 Transformers 직접 실행 방식으로 샘플 1~2페이지에서 시험했다. 300 DPI, 동일 GPU·입력·생성 상한으로 페이지당 약 7.55초·8.39초에 완료했고, 1.5 첫 페이지의 반복·상한 도달 문제는 재현되지 않았다. 첫 페이지 정답 초안에서 병기 한자 제외 후 공백 포함 오류율은 약 1.09%, 공백 무시 약 0.96%였다. 원시 PP-OCRv5는 각각 약 15.79%, 1.92%였다. 정답은 한 페이지에 한정되며 공백 포함 지표는 문단 경계 정확도를 뜻하지 않는다. 글자 오류는 남아 있으므로 VL 1.6을 유망 후보로 유지하고 최종 확정은 보류한다.

공식 자료: [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR), [지원 언어](https://www.paddleocr.ai/main/en/version3.x/pipeline_usage/OCR.html), [PP-OCRv6](https://www.paddleocr.ai/latest/en/version3.x/algorithm/PP-OCRv6/PP-OCRv6.html), [VL 1.6](https://huggingface.co/PaddlePaddle/PaddleOCR-VL-1.6).

## Qwen 모델

현재 비교 후보는 Alibaba Qwen 팀의 **Qwen3-VL-2B-Instruct**다. 이미지를 보고 글자를 읽거나 이미지 내용에 답하는 시각·언어 모델이며, `2B`는 약 20억 개의 모델 매개변수 규모, `Instruct`는 사용자 지시를 따르도록 조정한 버전을 뜻한다. 모델 카드는 Apache-2.0 라이선스와 다국어 OCR 기능을 명시한다. [공식 모델 카드](https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct).

프로젝트에서는 PDF를 이미지로 만든 뒤 보이는 글자를 읽기 순서대로 옮겨 적도록 지시한다. 파일은 로컬 모델로 처리하고 설명·요약·추측을 추가하지 않도록 요청한다. 생성 모델의 오류 가능성은 남으므로 원문 대조가 필요하다. 현재 실행 방식은 줄별 위치·신뢰도를 제공하지 않아 임의로 만들지 않는다. 한국어 품질 비교 후보로 유지하며 최종 모델로 확정하지 않았다.

## 문서 종류별 흐름과 Markdown 기획 추가 (2026-10-12)

사용자 요청에 따라 텍스트 중심 문서의 기본 흐름은 PP-OCRv5 + TXT로, 표·차트·수식·다단 등이 있는 복잡한 문서는 VL 1.6 + Markdown으로 나눈다. 모델별 설명은 모델 선택 옆 정보 아이콘을 눌렀을 때만 보여주는 기능으로 계획했다. 상세 범위는 [모델 안내와 출력 형식 설계](../MODEL_AND_EXPORT.md)를 따른다.

이 선택은 문서·출력 목적과 속도·위치 정보·보정 연결을 종합한 개발 방향이다. 기존 샘플에서 PP-OCRv5는 빠른 처리를 확인했고 VL 1.6은 일부 문자 정확도 지표가 더 좋았다. 기록된 수치를 바꾸거나 텍스트 문서에서 PP-OCRv5가 항상 더 정확하다고 결론 내리지 않는다. 복잡한 문서의 비교는 별도 샘플이 필요하다.

VL 1.6 공식 모델 카드에서 문서 파이프라인과 `save_to_markdown` 경로, Transformers 직접 실행 예제의 요소 인식 범위를 확인했다. 현재 앱은 직접 텍스트 인식 경로이므로 구조화 출력에는 공식 문서 파이프라인·추가 모델·결과 형식 연결이 필요하다. 공식 안내의 패키지 요구 버전과 현재 설치 버전이 다르므로 코드 도입 시 환경 호환성을 확인한다. 이번 작업은 기획·문서 반영이며 새 파이프라인의 설치·구조화 OCR·Markdown 저장 검증은 수행하지 않았다. [공식 VL 1.6 안내](https://huggingface.co/PaddlePaddle/PaddleOCR-VL-1.6).
