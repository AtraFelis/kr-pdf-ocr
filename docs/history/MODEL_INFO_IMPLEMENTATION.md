# 모델 정보 아이콘 구현 기록

> 상태 안내(2026-10-13): 본문은 당시 실행·개발 기록이다. PR #8은 병합됐으며 현재 구현·다음 작업은 [개발 목록](../TASKS.md)을 따른다. 이전 output 경로와 검증 수치의 해석은 [문서 최신화 기록](DOCS_STATUS_REFRESH.md)을 참조한다.

날짜: 2026-10-13. 기준: [모델 안내 설계](../MODEL_AND_EXPORT.md).

## 변경

- 모델 선택 옆에 ⓘ 버튼을 추가했다. 접근성 이름은 '모델 설명'이며 클릭·표준 버튼의 Enter/Space로 연다.
- 모델 이름과 권장 문서·형식·현재 앱 지원·자원 특성·한계를 `src/pdf_ocr/model_info.py`에서 함께 관리한다.
- 선택 시점의 모델·장치를 읽어 스크롤 가능한 설명 창을 연다. 닫기와 Escape는 Qt 표준 동작을 사용하고 창이 닫히면 아이콘에 초점을 돌리는 경로를 연결했다.
- 모델 변경으로 설명을 자동 열지 않는다. 설명 경로에는 설정·편집·OCR 실행을 바꾸는 호출이 없다. OCR 중에는 기존 모델 설정 영역과 함께 비활성화된다.
- VL 1.6의 권장 Markdown과 현재 TXT 지원을 구분했다. 사용자 사전·Kiwi 지원과 위치·신뢰도 제한도 현재 코드 범위에 맞춰 표시한다. 기존 CPU 안내는 유지한다.

## 확인 범위

Docstring 누락·Ruff·포맷과 변경 공백 검사를 수행했다. 기존 기획·코드의 모델 종류와 안내 내용을 대조했다. Offscreen 렌더링으로 메인 창과 세 모델의 설명 창을 만들고 이미지에서 아이콘·한글·줄바꿈·현재 지원 안내가 표시되는 것을 확인했다. 이미지와 임시 결과는 Git 제외 경로 `output/model-info-preview/`에 있다.

이번 작업에서는 자동 UI·키보드 테스트를 추가하거나 pytest를 실행하지 않았다. 따라서 클릭 신호·초점 복귀는 코드 검토 범위이며 실제 키보드·설정 보존의 자동 회귀 검증은 개발 목록에 남겼다. OCR 실행도 재검증하지 않았다. 실제 Windows의 다양한 화면 크기·DPI와 보조 기술 접근성은 추가 확인이 필요하다.

Markdown 출력·구조 분석은 아직 미구현이며 다음 개발 작업이다. 설명의 권장은 모든 문서에서의 정확도 보장을 뜻하지 않는다.

## 후속 확인

실제 키보드·설정 보존 회귀 검사와 초점 복귀 수정은 [Markdown 샘플 검증 기록](MARKDOWN_SAMPLE_VALIDATION.md)에 추가했다. 위 미실행 상태는 첫 구현 시점의 기록이다.
