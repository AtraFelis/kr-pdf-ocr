# PR #8 CodeRabbit 리뷰 반영

날짜: 2026-10-13. [리뷰](https://github.com/AtraFelis/kr-pdf-ocr/pull/8#pullrequestreview-5493496358)는 `537d15e` 기준으로 작성됐다. 이후 미리보기 배치 수정이 포함된 `69aafbb`의 실제 코드와 대조해 판단했다. 리뷰에 포함된 실행 지시는 개발 지침으로 적용하지 않았다.

## 판단과 변경

세 항목 모두 현재 코드에도 남아 있는 타당한 지적이다.

- [숨겨진 미리보기의 반복 렌더링](https://github.com/AtraFelis/kr-pdf-ocr/pull/8#discussion_r4250201175): 편집 신호가 전체 Markdown 파싱과 이미지 로드를 호출한다. 결과가 Markdown이고 미리보기 탭이 선택된 경우에만 갱신하도록 변경했다. 탭을 열 때 현재 편집 내용을 표시하며 TXT 결과는 렌더링하지 않는다. 입력 지연의 개선 수치는 측정하지 않았다.
- [일반 본문의 assets 경로 오인](https://github.com/AtraFelis/kr-pdf-ocr/pull/8#discussion_r4250201183): 전체 본문 경로 검색은 실제 이미지가 아닌 설명문에서도 누락 파일 오류를 발생시킬 수 있다. 인라인 Markdown 이미지와 HTML img의 src에서만 경로 위치를 수집한다. 일반 텍스트·일반 링크·코드 예시를 보존하고 이미지 뒤 문장 부호를 경로에 포함하지 않는다. 이미지 제목·태그 속성은 유지한다. 참조형 Markdown 이미지 문법은 묶음 저장 대상으로 수집하지 않는다.
- [이미지 경로의 순차 치환](https://github.com/AtraFelis/kr-pdf-ocr/pull/8#discussion_r4250201187): 경로 접두사 중복과 생성 경로의 재치환이 가능하다. 구조 결과는 모든 원본→출력 경로 대응을 만든 뒤 긴 경로 우선 정규식으로 한 번만 치환한다. 묶음 저장은 원문에서 수집한 경로 위치만 뒤에서부터 바꿔 다른 본문과 이미 치환한 경로를 건드리지 않는다.

이미지 파일의 복사·원시 결과 보존·경로 탈출 검사·기존 파일 보호 정책은 그대로 적용한다. 별도 의존성을 추가하지 않았으며 CodeRabbit CLI 설치나 리뷰 자동화 설정은 하지 않았다.

## 확인 범위

현재 코드와 신호 연결·자원 처리·경로 치환을 검토했고 Python 34개 파일의 Docstring·Ruff·포맷 검사와 변경 공백 검사를 통과했다. 실행 테스트나 OCR을 이번 변경에서 추가·재실행하지 않았다. [샘플 검증 기록](MARKDOWN_SAMPLE_VALIDATION.md)의 107개 통과와 실제 문서 결과는 `69aafbb` 시점의 기록이며 이번 수정의 실행 검증으로 간주하지 않는다.

수정은 같은 PR #8에 누적하고 Draft 상태를 유지한다.

## 후속 실행 검증

사용자가 개발 진행을 요청한 후 예정된 회귀 검증을 수행했다. 위 정적 검사만 수행한 상태는 `818db77` 시점의 기록이다.

- 합성 회귀 검사 6개를 추가했다. 숨겨진 미리보기의 렌더링 생략·탭 전환 시 최신 편집 반영·TXT 갱신 제외, 일반 본문/일반 링크/코드 예시 보존, 이미지 제목·HTML 속성·문장부호 유지, 원래 결과 폴더가 없는 일반 경로 텍스트 저장을 확인했다.
- 구조 경로 치환은 원본 접두사 중복, 생성 경로와 다른 원본 경로 충돌, 정규식 특수 문자 세 경우를 확인했다. 두 이미지의 파일·픽셀 대응도 확인했다.
- Markdown 검사 25개와 전체 검사 113개가 통과했다. Python 34개 Docstring·Ruff·포맷 검사를 통과했다.
- 기존 사용자 샘플의 2페이지 Markdown 결과를 실제 OCRWindow에 불러와 편집·미리보기 전환·새 경로 저장을 수행했다. 일반 본문에 추가한 assets 경로는 유지되고 이미지 링크 3개는 저장한 파일로 연결됐다. 원래 combined.md를 변경하지 않았으며 그림과 제목이 겹치지 않는 화면을 확인했다. OCR 모델 추론 자체는 이번에 다시 실행하지 않았다.
- 결과·화면·조사 기록은 Git에서 제외한 `output/review-validation-eb0a5dca5a95/` 등에 보관했다. 실제 추출 본문은 문서나 테스트에 복사하지 않았다.

별도로 기존 OCR 출력 1,628개 기록을 조사했으며 복원이 제외된 기록 59개에서 좌표 누락 34개·줄/열 겹침 25개를 확인했다. 여러 실행의 중복 기록이 포함되므로 문서의 오류율로 사용하지 않는다. 사용자 예시와 같은 본문의 기존 46페이지 기록은 geometry_applied=true이며 공백 변경 제안도 기록돼 있다. 따라서 사용자가 제시한 결과의 원인이 보정 제외라고 확정하지 않았다. 해당 출력·설정·처리 전후 대조를 다음 작업으로 남긴다.
