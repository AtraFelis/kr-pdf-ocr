# 모델 평가 변경 제외와 페이지 간 연결 구현

날짜: 2026-10-13. 사용자가 모델 학습·언어 모델 문장 교정을 제외하고, 해당 평가 변경을 되돌린 뒤 페이지 사이 문단 연결을 진행하도록 요청했다.

## 작업 기준

PR #10은 main에 미병합 상태였으므로 닫았다. PR #11도 이미 닫힌 상태다. 기존 main `28fef94`에서 `codex/cross-page-paragraphs`를 시작해 모델 평가 코드·학습 기획 변경을 포함하지 않았다. 병합된 이력을 되돌리는 revert 커밋이나 강제 초기화가 필요했던 상태가 아니다. 로컬 모델·과거 평가 출력·원본 문서는 삭제하지 않았다.

이전 학습 기획 브랜치에서 사용자가 삭제한 기획서 파일은 복원하지 않았다. 현재 main 기반에는 해당 파일이 없다. 현재 OCR·Kiwi·사용자 사전·원본 이미지 재인식은 유지한다. 모델 학습과 별도 언어 모델의 문장 교정은 계획에서 제외한다.

## 구현

연결 옵션은 기본 꺼짐이며 PP-OCRv5 TXT의 문단 복원 결과만 대상으로 한다. CLI `--join-pages`, 저장 JSON 재보정, GUI 체크박스를 연결했다. 통합 TXT만 바꾸며 페이지별 결과와 원시 줄·좌표·내용은 보존한다. 연결 판단·출처·모호한 경계는 `connections.json`에 기록한다.

연속 페이지·정상 좌표·추출 영역·본문 폭/글자 높이·마지막 줄 길이·다음 들여쓰기·종결 부호를 검사한다. 명확한 조사는 붙이고 모호한 단어 경계는 공백으로 연결한 뒤 확인 대상으로 기록한다. 통합 전후 공백 외 글자가 달라지면 오류로 중단한다. 머리말·쪽번호를 임의로 삭제하지 않는다. 자세한 제한은 [사용법](../PAGE_CONNECTION.md)을 따른다.

## 실행 확인

직접 작성한 합성 2페이지 JSON을 새 폴더에서 연결 옵션 켬/끔으로 재처리했다. 켠 결과에서 `제조사`와 다음 페이지의 `에`가 붙고, 끈 결과는 페이지 사이 빈 줄을 유지했다. 실제 저장 OCR `ocr-run-02`의 1~2페이지도 Kiwi와 연결 옵션으로 새 출력에 재처리했다. 해당 경계는 마지막 줄이 짧아 보존됐으며 `short_last_line` 이유가 기록됐다. 실제 본문은 이 문서에 복사하지 않았다.

합성 결과는 `output/page-join-example-enabled/`, `output/page-join-example-disabled/`, 저장 샘플 실행은 `output/page-join-saved-sample/`에 보관한다. 이번 실행은 저장 JSON을 재처리했으며 OCR 모델을 새로 실행한 결과가 아니다. 새 OCR CLI 연결과 실제 GUI 조작·모든 보존/오류 조건·다양한 문서/회전/DPI·취소/부분 실패의 실제 실행은 추가 확인이 필요하다. 별도 pytest 회귀 검사는 이번 요청에서 추가·실행하지 않았다.

Docstring 검사(Python 39개)·Ruff·포맷·Git 공백 검사를 통과했다. Markdown 33개에서 코드 예제 밖 로컬 링크 대상 158개의 존재를 확인했고 CLI·재처리 도움말을 실행했다. 정적 검사 통과를 실제 GUI·OCR 실행 검증으로 표현하지 않는다.

후속 PR #12 리뷰 수정·전체 회귀 160개·실제 17페이지 재처리 확인은 [별도 기록](PR12_REVIEW_AND_PAGE17.md)을 따른다. 위 pytest 미실행 표기는 최초 페이지 연결 커밋 c69edd7 당시 상태다.
