# 실제 짧은 대사·말줄임표 오류의 VLM 재인식

> 상태 안내(2026-10-13): 본문은 당시 실행·개발 기록이다. PR #8은 병합됐으며 현재 구현·다음 작업은 [개발 목록](../TASKS.md)을 따른다. 이전 output 경로와 검증 수치의 해석은 [문서 최신화 기록](DOCS_STATUS_REFRESH.md)을 참조한다.

날짜: 2026-10-13. 사용자가 기본 TXT에 짧은 대사의 잘못된 영문/기호, 마침표·말줄임표 누락이 남는다고 알렸다. 기존 기능은 PP-OCRv5의 여백·배율별 후보를 제시하며 기본 TXT에는 자동 반영하지 않았다. 합성 자료의 회복만으로 실제 오류가 해결됐다고 판단하지 않았다.

## 실제 원인과 비교

저장된 79·88페이지 원시 결과와 PNG에서 문제 줄을 찾았다. PP-OCRv5는 해당 짧은 영역을 다시 읽어도 잘못된 영문·기호나 빈 결과를 반환했다. 따라서 같은 모델의 확대만으로 해결할 수 없음을 확인했다.

- VL 1.6은 실제 두 곳의 짧은 대사를 `“응?”`으로 읽었고, 다른 짧은 대사에서 빠진 말줄임표를 읽었다.
- 긴 대사의 앞쪽 말줄임표는 VL 1.6이 놓친 반면 Qwen은 보존했다.
- Qwen도 한 짧은 대사에서 전혀 다른 문자를 반환했다. 모델 결과를 점수나 다수결만으로 자동 채택하지 않는다.

실제 본문은 Git에 복사하지 않았다. 원시 데이터와 실험은 `output/real-short-errors/`, 최종 기능 실행 결과는 `output/visual-retry-b392c4e44630/` 등에 보관한다. 기존 사용자 결과를 검증용으로 복사해 실험했으며 원래 파일은 수정하지 않았다.

## 구현

비교 창에서 선택 줄을 VL 1.6·Qwen으로 다시 읽도록 별도 프로세스를 연결했다. 기존 PP 결과에 재인식 후보가 없어도 해당 줄을 선택할 수 있다. 원본 PNG·줄 좌표와 선택 영역을 이용하고 여백이 앞뒤 줄에 침범하지 않도록 제한한다. 소켓 연결을 차단하며 모델은 로컬 경로만 사용한다. 실패·취소·빈 결과·잘린 결과에서 기존 원시 JSON을 유지한다. VLM 후보에는 신뢰도 수치를 만들지 않는다.

후보 복사 외에 사용자 선택으로 편집기에 반영하는 버튼을 추가했다. 공백을 무시해 유일하게 일치하는 구간에만 반영하고 중복·수정본·영문 단어 일부는 교체하지 않는다. UTF-16 위치 변환으로 이모지가 앞에 있어도 정확한 구간을 편집한다. 실행 취소와 기존 파일 보존을 지원한다.

## 검증과 제한

실제 GUI에서 79페이지의 VLM 재인식·원시/후보 비교·후보 반영·실행 취소·원시 줄과 문단 결과 보존을 확인했다. 최종 worker에서 88페이지의 두 짧은 대사와 79페이지 긴 대사도 다시 인식했다. 원문에 있는 말줄임표를 읽는 후보를 확인했지만 모든 문장부호의 정확성을 보장하지 않는다.

합성 회귀 검사 8개를 추가했고 전체 152개 검사, Python 38개 Docstring·Ruff·포맷 검사를 통과했다. 인용/말줄임표 선정, 영역/원시 결과 보존, 잘린 결과 거부, 인접 줄 제외, 유일 구간·중복·수정본·영문 부분 단어·이모지/실행 취소를 포함한다.

이번 최종 VLM 기능은 GPU의 해당 영역에서 확인했으며 CPU VLM 실행·전체 문서 CER·모든 말줄임표 개수·고유명사 문자 교정은 추가 평가다. 기존 Ready PR #8에 누적하며 자동 병합은 하지 않는다.
