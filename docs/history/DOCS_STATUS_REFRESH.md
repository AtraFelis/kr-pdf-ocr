## 갱신 이유와 확인 근거

기획서·개발 목록·문자 교정 도입 계획에는 PR #8 리뷰 수정과 오류 샘플 보정 중단 수정·짧은 대사 재인식이 다음 작업으로 남아 있었다. 실제 main의 병합 커밋은 `d6930a1`이며 관련 구현 커밋은 `967d6dc`(작은 닫는 부호), `bcd9393`(인용문 공백), `c65cdbb`(PP 재인식), `da19b55`(선택 VLM 재인식·후보 반영)다.

후속 구현을 추가하면서 요약 문서의 순서를 함께 갱신하지 않은 것으로 추정한다. 과거 검증 기록의 Draft·미구현 문구는 작성 시점의 사실로 보존하고 현재 상태 안내를 추가했다. AGENTS.md의 원문 보존·좌표 없는 결과 보존 정책과 구현은 일치한다. 문서 우선순위를 근거로 미구현 기능을 완료 처리하지 않았다.

현재 다음 작업은 `gec_kr`의 버전·라이선스·실행 조건 확인과 로컬 비교 평가다. 정상 문장·고유명사·대사 말투의 과잉 교정, 글자·공백·문장부호 개선, CPU/GPU 시간·메모리를 비교한다. 모델 설치와 제품 연결은 아직 수행하지 않았다. 상세 순서는 [개발 목록](../TASKS.md)을 따른다.

- PP-OCRv5 후보 비교·선택 줄의 VL 1.6/Qwen 재인식·편집기 반영·실행 취소를 제공한다. 모든 짧은 대사·마침표·말줄임표의 인식 정확도가 해결된 것은 아니다.
- 좌표 누락·미해결 겹침에서는 여전히 페이지 전체의 기존 줄을 보존하고 Kiwi를 건너뛴다. 제외 이유 상세 화면·정상 영역 부분 복원은 후속 작업이다.

## 이전 output 보관 위치

2026-10-13 정리에서 테스트·임시 파일 75개를 삭제하고 이전 결과·보고서 94개를 `output/_archive/cleanup-20261013-150057/`로 옮겼다. 실제 PDF·모델·사용자 사전은 변경하지 않았다. 보관은 삭제가 아니며 약 1.6GB를 계속 사용한다.

과거 기록의 `output/ocr-run-02/`, `output/ocr-error-verified-60aa5e58b0ea-spacing/`, `output/real-short-errors/`, `output/visual-retry-b392c4e44630/` 등은 해당 보관 폴더 아래의 같은 이름을 찾는다. 정확한 이동 목록은 보관 폴더의 `output-cleanup.json`, 삭제한 병합 브랜치의 커밋 식별값은 `branches.json`에 있다. 이 자료는 로컬 전용이며 Git에서 제외된다. 과거 로그·임시 스크립트 중 삭제 항목은 복원 가능하다고 표현하지 않는다.

최근 결과 4개와 Markdown 내보내기 묶음 `output/sample-md-gui-01/`은 기존 위치에 남겼다. 새 OCR 결과는 기존처럼 `output/`의 새 폴더에 생성한다. 보관 경로는 이 컴퓨터의 기록이며 새 체크아웃에 포함되지 않는다.

## 문서 검토 범위

기획·개발 목록·사용법·README와 관련 기록의 상태 및 상대 링크를 검토하고, 저장 JSON 예제의 보관 경로와 명령의 모듈·스크립트·옵션 정의를 확인한다. 문서만 변경하므로 OCR 재실행·모델 설치·코드 테스트·빌드는 수행하지 않는다. 배포 빌드는 여전히 미설정이다.
