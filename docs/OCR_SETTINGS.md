# OCR 설정과 품질 수치

## 사용자가 조정할 수 있는 검출 기준

PP-OCRv5 + TXT에서 화면의 **글자 영역 검출 기준** 또는 CLI의 `--det-box-thresh`를 사용한다. 기본 0.50, 허용 범위 0.01~1.00이며 NaN·무한대·범위 밖 값은 거부한다. 화면 입력값은 같은 창에서 모델/출력 형식 전환 후에도 유지한다. 앱을 다시 열면 기본값으로 시작한다. OCR 중에는 잠기며 다음 새 OCR에만 적용한다.

이 값은 **검출한 사각형 안의 평균 픽셀 점수가 어느 정도 이상이어야 글자 영역으로 남길지** 결정한다. 인식 정확도 백분율이나 개별 글자의 인식 점수가 아니다.

- 값을 낮추면 약하게 검출된 실제 글자를 찾을 수 있지만 잡음도 증가할 수 있다.
- 값을 높이면 잡음을 제외하면서 실제 문장도 누락할 수 있다.
- 우선 기본 0.50을 사용한다. 누락이 있다면 같은 페이지에서 한 번에 0.05씩 낮춰 대조하고 잡음이 많다면 올려 대조한다. 최저값이 가장 정확한 설정은 아니다.

실제 전달값은 `summary.json.ocr_settings.text_det_box_thresh`에 기록한다. PP 단일 줄 재인식은 작업 엔진에 고정된 같은 값으로 실행한다. GUI VLM·Markdown에서는 입력을 비활성화하고 CLI는 해당 조합의 명시적 옵션을 거부한다. 실험적 VLM 줄 검출은 기존 기본값을 사용하며 이 옵션으로 바뀌지 않는다.

```powershell
.\.venv-paddle\Scripts\python.exe -m pdf_ocr.cli samples/input/sample.pdf --pages 1 --device gpu --det-box-thresh 0.45 --output "output/threshold-$(Get-Date -Format yyyyMMdd-HHmmss)"
```

영역 선택 밖의 글자를 찾거나 없는 문장을 생성하는 기능은 아니다. 새 값으로 결과를 비교하려면 OCR을 다시 실행한다. 저장 JSON 재보정·기존 편집 내용·기존 결과 파일은 변경하지 않는다. 17페이지 누락 사례와 일반 문서의 잡음 가능성은 [검출 수정 기록](history/OCR_DETECTION_OMISSION.md)을 따른다. 사용자 조정 구현의 실행 범위는 [설정 검증 기록](history/OCR_SETTINGS_CONTROL.md)을 참조한다.

## 그 밖의 품질 관련 수치

아래 모델 수치는 현재 설치한 PP-OCRv5 파이프라인 기준이다. 이번에 추가한 화면 조정은 검출 영역 기준 한 가지이며 나머지 모델 수치는 사용자 옵션으로 노출하지 않았다.

- **PDF 렌더링 DPI:** 기본 300. GUI OCR은 현재 고정이고 CLI `--dpi`에서 변경 가능하다. 해상도를 높이면 작은 글자에 유리할 수 있지만 처리 시간·메모리가 늘고 모델 내부 리사이즈 때문에 개선이 보장되지 않는다. 흐릿한 원본의 정보를 새로 만들지는 못한다. 미리보기 확대 배율과 다른 값이다.
- **글자 픽셀 판정 기준 `text_det_thresh`:** 설치 환경 기본 0.3. 검출 확률 지도에서 글자 픽셀을 구분한다. 검출 영역 평균값 기준과 다른 단계이며 낮추면 잡음도 포함될 수 있다.
- **영역 확장 비율 `text_det_unclip_ratio`:** 설치 환경 기본 1.5. 검출된 영역을 얼마나 확장할지 정한다. 커지면 경계 글자 잘림을 줄일 수 있지만 이웃 줄까지 포함할 수 있다.
- **검출 이미지 크기 제한 `text_det_limit_side_len` / `text_det_limit_type`:** 모델 입력 크기를 조정한다. 현재 설치 환경은 최소 짧은 변 64(`min`) 및 최대 긴 변 제한 4,000이며 무조건 64px로 축소한다는 뜻이 아니다. 모델 입력 크기와 속도·세부 검출의 관계를 별도 평가해야 한다.
- **인식 결과 제외 기준 `text_rec_score_thresh`:** 설치 환경 기본 0.0. 읽은 결과 중 점수가 낮은 것을 제외한다. 높인다고 잘못 읽은 글자가 정답으로 교정되지는 않으며 문장 누락이 증가할 수 있어 원시 결과 보존 정책과 함께 검토해야 한다.

CPU/GPU 선택은 자원·속도 설정이며 정확도 수치 조절은 아니다. Kiwi·사용자 사전은 OCR 글자를 바꾸지 않는 별도의 공백 보정이다. 서로 다른 설정을 비교할 때는 같은 PDF·페이지·영역·DPI·모델·장치를 유지하고 변경한 수치 한 가지만 비교한다.

모델 파라미터의 의미와 기본값 출처: [PaddleOCR 공식 OCR 파이프라인 문서](https://github.com/PaddlePaddle/PaddleOCR/blob/main/docs/version3.x/pipeline_usage/OCR.en.md). 실제 설치 환경의 설정도 대조했으며 라이브러리 업데이트 시 재확인한다.
