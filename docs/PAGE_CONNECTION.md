# 페이지 사이 문단 연결

## 사용

PP-OCRv5·TXT에서 **페이지 사이 문단 연결 · 확인 필요**를 체크한 뒤 OCR을 실행한다. 처음에는 꺼져 있다. 연결은 통합 편집기와 `combined.txt`에 적용하며 페이지별 TXT·원시 OCR JSON·좌표는 유지한다. 파일 저장은 기존처럼 별도로 한다.

머리말·쪽번호·각주가 본문 경계에 섞이면 연결을 방해하므로 필요하면 추출 영역에서 제외한다. 페이지 경계마다 문단의 끝과 시작을 원본으로 확인한다. 연결 결과를 켜고 끄는 동작은 이미 편집 중인 문서를 자동으로 바꾸지 않으며 다음 OCR/새 출력 재보정에 적용한다.

프로젝트 루트 PowerShell에서 실행한다. 출력은 존재하지 않는 새 폴더다.

```powershell
# 새 OCR과 페이지 연결
.\.venv-paddle\Scripts\python.exe -m pdf_ocr.cli samples/input/sample.pdf --pages 1-2 --device cpu --repair-spacing --join-pages --output "output/connected-$(Get-Date -Format yyyyMMdd-HHmmss)"
# 저장 JSON의 문단 복원·Kiwi·페이지 연결: OCR 모델 재실행 없음
.\.venv\Scripts\python.exe -m pdf_ocr.restore output/_archive/cleanup-20261013-150057/ocr-run-02 --repair-spacing --join-pages --output "output/connected-saved-$(Get-Date -Format yyyyMMdd-HHmmss)"
```

저장 결과를 사용할 때 입력 경로를 실제 JSON 또는 결과 폴더로 바꾼다. UI의 저장 OCR 비교·재보정도 현재 연결 옵션을 사용하지만 기존 편집기는 유지한다. 단일 페이지 재보정에는 연결할 경계가 없다.

## 연결 판단

- PDF 번호가 연속인 완료 페이지 사이만 연결한다. 제외·빈 페이지·실패 때문에 번호가 건너뛰면 연결하지 않는다.
- 양쪽 페이지가 좌표를 사용하는 단일 본문 복원이어야 한다. 좌표 누락·겹침·복원 제외는 보존한다.
- 같은 상대 추출 영역, 유사한 본문 폭·글자 높이, 충분히 긴 마지막 줄, 들여쓰기 없는 다음 시작을 요구한다.
- 끝난 문장/닫힌 대사·목록·쪽번호 형태, 짧은 다음 첫 문단·글자 크기 변화 등은 연결하지 않는다. 마침표만으로 모든 문단 경계를 판단하지 않지만 페이지 연결에서는 보수적으로 보존한다.
- 명확한 조사 연결은 `제조사\n에 → 제조사에`처럼 공백 없이 잇는다. 그 외 모호한 단어 경계는 한 칸 공백으로 연결하고 `review_required=true`로 확인 대상으로 남긴다. 단어 내부인지 완전히 판정하는 기능은 아니다.
- 글자·문장부호를 추가/삭제/교정하지 않는다. 통합 전후 공백 외 글자 보존을 검사한다. 경계 연결 뒤 Kiwi를 다시 실행하지 않는다.

옵션을 꺼 두면 기존처럼 페이지 사이에 빈 줄을 넣는다. VLM TXT·Markdown·`--keep-line-breaks`와 연결 옵션을 함께 지정하면 CLI에서 거부한다. UI에서는 미지원 조합의 옵션을 비활성화한다.

## 기록과 제한

결과 폴더의 `connections.json`에 통합 텍스트·문단별 원본 페이지/문단/줄 인덱스·경계별 연결 여부·보존 이유·공백과 검토 필요 여부를 기록한다. 완료 페이지마다 통합 파일을 원자적으로 갱신한다. 취소·실패에서는 이미 저장한 통합 결과와 페이지 파일이 남는다.

GUI의 완료 안내에는 연결한 경계 수와 모호한 연결을 포함한 확인 항목 수가 표시된다. 상세 경계 목록을 편집하는 전용 화면은 아직 제공하지 않는다. 페이지별 TXT와 통합 TXT의 문단 경계가 달라지는 것은 의도된 동작이다. 사전 재보정의 보정 전·사전 미적용 비교 TXT에도 연결 옵션을 적용한다.

단일 본문 휴리스틱이다. 여러 단·표·머리말·목차·같은 글자 크기의 제목, 페이지 중간에서 끝나는 추출 영역, 다양한 판형/DPI는 추가 평가가 필요하다. 영역을 잘라 누락된 문자를 복구하지 않는다. [구현·실행 기록](history/PAGE_CONNECTION.md)을 참조한다.
