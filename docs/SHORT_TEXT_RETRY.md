# 짧은 대사·문장부호 재인식

PP-OCRv5의 TXT에서 선택할 수 있다. 화면에서 **짧은 대사·문장부호 재인식 후보**를 켠 뒤 OCR을 실행하고 **재인식 후보 비교**를 연다. 후보별 원시 인식·재인식 결과·이미지·모델 점수 또는 실패 이유를 확인한다. 원하는 후보를 복사하거나 **선택 후보를 편집기에 반영**한 뒤 결과를 저장한다. 모델 결과만으로 편집 내용·TXT·원시 결과를 자동 교체하지 않는다.

## PP-OCRv5가 계속 잘못 읽는 경우

비교 창에서 해당 줄을 선택하고 VL 1.6 또는 Qwen을 고른 뒤 **선택 영역을 다른 로컬 모델로 재인식**을 누른다. 기존 후보가 없는 결과에도 짧은 줄·따옴표·말줄임표 등을 선택할 수 있다. 로컬 VLM 모델과 `.venv` 환경이 필요하며 다운로드는 별도로 진행한다. CPU/GPU는 작업 화면의 명시적인 장치 선택을 따른다. CPU는 오래 걸릴 수 있다.

별도 프로세스에서 원본 PNG의 선택 영역 안을 읽으며 앞뒤 줄의 일부가 섞이지 않도록 좌표로 여백을 제한한다. 창을 닫으면 소유한 프로세스만 중단한다. 원시 인식·문단 결과는 유지하며 후보와 이미지만 페이지 JSON에 원자적으로 추가한다. VLM이 제공하지 않는 점수는 **미제공**으로 표시한다. 빈 결과나 토큰 상한으로 잘린 결과는 실패로 처리한다.

사용자가 후보 반영을 누르면 현재 편집기에서 원시 문장과 공백을 제외하고 유일하게 일치하는 구간만 교체한다. 영문 단어의 일부나 서로 다른 문단을 가로질러 찾지 않는다. 일치 구간이 없거나 여러 곳이면 후보를 복사해 직접 수정하도록 안내한다. 다른 편집 내용과 파일은 유지하며 실행 취소로 되돌릴 수 있다. 파일 저장은 별도로 한다.

CLI는 `--retry-short-lines`를 사용한다. VLM·Markdown 조합은 실행 전에 거부한다. 실제 실행 명령은 [AGENTS.md](../AGENTS.md)에 있다.

## 선정과 처리

- 공백 제외 6글자 이하, 모델 점수 0.88 미만, `다/요/죠/까/니`로 끝나고 종결 부호가 없는 줄을 후보로 선정한다. 이 기준은 오류 판정이 아니다. 정상 줄이나 이어지는 본문 줄도 선정될 수 있다.
- 페이지별 최대 24개 줄에 대해 줄 높이의 10%/25% 여백과 2배/3배 재표본화 조건으로 기존 로컬 검출·인식 모델을 다시 실행한다. 처리 시간이 늘어난다. CPU 자원 안내도 적용된다.
- 따옴표·말줄임표를 포함한 줄도 점수가 높더라도 비교 대상으로 선정한다. VLM 선택 재인식은 사용자가 지정한 한 줄만 실행한다.
- 좌표 없는 줄·잘못된 크기는 제외한다. 선택한 페이지·영역 바깥을 읽지 않으며 여백은 입력 경계 안으로 제한한다. 입력 기준/전체 페이지 기준 좌표를 각각 기록한다.
- 단일 줄로 검출되지 않으면 후보 실패로 표시한다. 다른 조건의 성공 후보와 기본 OCR 완료 결과는 유지한다. 이미지에서 완전히 누락된 줄을 발견하는 기능은 아니다.

## 보존과 한계

완전히 빠진 줄은 기존 줄 선택 재인식으로 찾을 수 없다. PP-OCRv5의 기본 검출 영역 점수 기준은 0.5로 명시하며, 17페이지의 누락 대사를 같은 이미지에서 다시 검출한 범위는 [기록](history/OCR_DETECTION_OMISSION.md)을 따른다. 새 설정으로 OCR을 다시 실행한 뒤 인식된 줄을 후보 비교에서 선택한다. 저장 JSON 재보정만으로 빠진 줄을 만들지 않는다. 검출 설정은 단일 줄 PP-OCRv5 재인식에도 동일하게 적용된다.

페이지 JSON의 `lines`는 기본 OCR 원시 결과이며 `recognition_retry`에 후보·점수·실패·배율·여백·좌표와 이미지 경로를 기록한다. 이미지는 결과 내부 `retry/`에 저장한다. 재인식 시간은 `recognition_retry_seconds`, 전체 페이지 시간은 `seconds`에 기록한다. 기본 TXT·문단 복원·Kiwi는 원시 줄을 사용하며 후보는 자동 반영하지 않는다.

모델 점수는 정답 확률이나 서로 다른 후보의 신뢰도 보장이 아니다. 확대는 재표본화이므로 원본에 없는 영상 정보를 복원하지 않는다. 재인식이 원문보다 나빠지거나 마침표를 잃는 경우도 있어 반드시 이미지를 확인한다. 마침표를 규칙으로 덧붙이거나 `ac`를 무조건 `응?`으로 치환하지 않는다. 처음에는 체크를 해제한 상태다.
